Sent during the declare-attackers step of combat. The engine tells the client
which creatures are able to attack and which players, planeswalkers, or battles
each one may attack - for example, choosing to swing with a Grizzly Bears at the
opponent's face while leaving an untapped blocker back.

![The chooseAttackers prompt in the Manabrew client](/protocol/declare-attackers.webp)

## Arguments

`input.type` is `"chooseAttackers"`. The remaining fields:

<ProtocolType slug="choose-attackers" />

## Response

```ts
type ChooseAttackersOutput = { type: "declareAttackers"; assignments: AttackAssignment[] };
type AttackAssignment = { attackerId: string; targetId: string };
```

Return one `AttackAssignment` per attacking creature: each assignment sends one
creature at one target. Creatures the player chooses not to attack with are
simply omitted.

Each attacker may only attack a target in its own `validTargetIds`. The engine
rejects an assignment outside that list, or a creature assigned twice, with an
`illegalAssignment` error and sends the prompt again. A creature with
`mustAttack` has to attack if able; `mustAttackTargetIds` names the targets that
meet its requirement (all of them when any target will do). Leaving such a
creature out makes the engine ask again.

## Example

```json
{
  "promptId": 7,
  "decidingPlayerId": "player-0",
  "input": {
    "type": "chooseAttackers",
    "attackers": [
      { "attackerId": "bf-3", "validTargetIds": ["player-1", "pw-1"], "mustAttack": false },
      {
        "attackerId": "bf-4",
        "validTargetIds": ["player-1", "pw-1"],
        "mustAttack": true,
        "mustAttackTargetIds": ["pw-1"]
      }
    ],
    "attackTargets": [
      { "id": "player-1", "label": "Opponent", "kind": "player" },
      { "id": "pw-1", "label": "Jace, the Mind Sculptor", "kind": "planeswalker" }
    ]
  }
}
```

```json
{
  "kind": "response",
  "promptId": 7,
  "action": {
    "type": "chooseAttackers",
    "output": {
      "type": "declareAttackers",
      "assignments": [
        {
          "attackerId": "bf-3",
          "targetId": "player-1"
        },
        {
          "attackerId": "bf-4",
          "targetId": "pw-1"
        }
      ]
    }
  }
}
```
